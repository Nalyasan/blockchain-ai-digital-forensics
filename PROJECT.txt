## 4. Interface Contracts
1. Endpoint Acquisition <-> Evidence Store:
   forensics.endpoint.schemas.EvidenceSourceAdapter emitting AcquisitionResult
   (source_id, consent_scope, original_sha256, copy_sha256, timestamp_utc, records).
   Append-only persistence into data/endpoint_evidence.db.
2. Evidence Store <-> ML/XAI & Rule Engine:
   Independent ground truth without alerts table leakage. Normalized amounts:
   normalized_amount = raw_amount / (10 ** token_decimals). Isolated temporal windows.
3. ML/XAI <-> AI Investigator:
   MLAnomalyDetection schema (score, confidence, model_hash, top_features, fidelity).
   MITREMapping schema (technique_id, tactic_id, required_evidence, status: MAPPED/NOT_MAPPED).
4. ML/XAI <-> ZKML Engine:
   ONNX opset 14/15. Binding hash = sha256(model_hash || circuit_version || input_commitment
   || output_commitment || inference_record_id).
5. ZKML Engine <-> Smart Contract Verifier (InferenceVerifier.sol):
   verifyInference(bytes proof, uint256[] publicSignals, bytes32 modelHash, bytes32 recordId).
6. Evidence Package <-> Custody & Identity (EvidenceRegistryDID.sol):
   logEvidenceWithSignature(bytes32 evidenceHash, string did, uint8 role, uint256 nonce,
   uint256 deadline, bytes signature). EIP-712 domain: EvidenceRegistryDID v1.
7. Evaluation Demos Entry Points:
   scripts/demo_d1_evm.py, scripts/demo_d2_host.py, scripts/demo_d3_adversarial.py.
8. Portable Release Bundle:
   Standalone directory with setup.ps1, smoke_test.ps1, run_full_tests.ps1,
   verify_integrity.ps1, SHA256SUMS.txt, and wheelhouse dependencies.
